# Status Archive

Store release snapshots here.

When a release ships:

1. Copy [../../IMPLEMENTATION_STATUS.md](../../IMPLEMENTATION_STATUS.md) into this folder with the release label.
2. Copy the detailed status files from [../](../) into a release-named subfolder or matching release-labeled files.
3. Refresh the active status files for the next project scope.

Do not use archived files as the source for current implementation status.
